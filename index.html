チャンネル登録日チェッカー

チャンネル登録日チェッカーは、あなたが YouTube のチャンネルをいつ登録したかを一覧で表示するツールです。登録日は YouTube の画面上では確認できませんが、YouTube Data API から取得できます。

本サービスは、登録チャンネルの一覧と各チャンネルの登録日を読み取るためだけに youtube.readonly（読み取り専用）の権限を使用します。チャンネル登録の追加・削除は行いません。

取得したデータは利用者のブラウザ上でのみ処理され、サーバーには保存されません。運営者を含む第三者が受け取ることはありません。
